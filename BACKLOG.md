# PickMyPlate backlog

Small, real tasks, most of them 30–60 minutes each. Pick one per session, do it, commit it, tick it off.
When you finish one, write a line in `DEVLOG.md`.

## Learn the code (do these first)
- [ ] Read `safeFor()` in `js/app.js` and explain it in your own words in DEVLOG
- [ ] Change the brand colour in `css/style.css` and see what changes
- [ ] Add a new dish to `sampleData()`
- [ ] Add a third course ("Side" or "Drink") to `COURSES` and test it
- [ ] Add 10 more emoji to the `EMOJIS` list

## Small improvements
- [ ] Show the dish's allergens on the "All done" screen (for staff to double-check)
- [ ] Add a "Clear diet card" reminder after each child
- [ ] Add a search box to the kitchen menu list
- [ ] Let staff reorder dishes (move up/down buttons)
- [ ] Add a "Drink" course with water/milk/juice
- [ ] Add a footer with version number and a link to the GitHub repo
- [ ] Replace the emoji sample dishes with your own food photos (edited in Photoshop)

## Accessibility (strong evidence for your niche)
- [ ] Check colour contrast with a free checker (e.g. WebAIM) and fix any failures
- [ ] Test the whole app using only the keyboard (Tab, Enter) and fix problems
- [ ] Test with a screen reader (Windows Narrator) and write up what you found
- [ ] Add an "Extra large pictures" setting
- [ ] Add a "Calm mode" (no animations, softer colours)
- [ ] Add a setting to choose the voice speed
